MOJEBH / LIFEOS — READY BUILD SOURCE

Upload ALL contents of this folder to the GitHub repository, including the
hidden .github folder.

Then GitHub -> Actions -> Build LifeOS Setup.exe -> Run workflow.

The Windows runner builds the actual LifeOS Setup.exe (x64). The user's PC
does not need Node.js or npm. The installed app uses an embedded runtime and
does not require Chrome/Edge to be opened.

Final installer target:
LifeOS Setup.exe -> one-click install -> LifeOS desktop app.
